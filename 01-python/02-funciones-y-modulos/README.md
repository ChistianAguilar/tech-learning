# 02 - Funciones y Módulos

## Descripción 

Proyecto para practicar la creación de funciones, el uso de módulos propios y la importación de módulos de Python.

## Qué aprederé

- Crear funciones con parárametros y valores de retrono 
- Funciones con parámetros opcionales 
- Crear módulos propios y reutilizarlos
- Importar módulos de la librería estándar de Python

## Archivo del proyecto

- `main.py` - Código principal
- `operaciones.py` - Módulo propio con funciones matemáticas
- `utilidades.py` - Módulo propio de fuciones de texto

## Cómo ejecutar
```bash
uv run main.py
```
