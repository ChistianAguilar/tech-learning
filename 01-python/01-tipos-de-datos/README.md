# 01 - Tipos de Datos

## Descripción

Proyecto para explorar y practicar todos los tipos de datos en Python, sus mérodos más útiles y cómo tranajar con ellos.

## Qué aprenderé 

- Tipos de datos básicos: str, int, float, bool
- Tipos de datos de colecciones: list, tuple, dict, set
- Métodos útilis de cada tipo
- Conversión estre tipos de datos

## Cómo ejecutar
```bash
uv run main.py
```

## Conceptos clave

- **str**: texto y sus métodos (upper, lower, split, replace)
- **int / float**: números y operaciones matemáticas
- **bool**: True/False y operadores lógicos
- **list**: colecciones ordenadas y modificables
- **dict**: pares clave/valor
- **ste**: colecciones de alementos únicos
