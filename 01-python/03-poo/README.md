# 03 - POO (Programación Orientada a Objetos)

## Descripción

Proyecto para aprender los conceptos fundamentales de la Programación Orientada a Objetos: clases, objetos, atributos, métodos y herencia y encapsulamiento.

## Qué aprenderé

- Crear clases y objetos
- Definir atributos y métodos
- Usar el contructor `__init__`
- Entender herencia entre clases
- Métodos especiales como `__str__`
- Encapsulamiento: atributos públicos, privados y protegidos

## Archivos del Proyecto
- `main.py` - Código principal con ejemplos de POO (clases, objetos, métodos)
- `herencia.py` - Ejemplos de herencia entre clases
- `encapsulamiento.py` - Ejemplos de atributos privados y protegidos

## Cómo ejecutar
```bash 
uv run main.py
uv run herencia.py
uv run encapsulamiento.py
```

## Conceptos clave

- **Clase**: Plantilla para crear objetos 
- **Objeto**: Instancia de una clase
- **Atributos**: Características del objeto
- **Métodos**: Funciones dentro de una clase
- **Herencia**: Una clase puede heredar de otra 
- **Encapsulamiento**: Controlar el acceso a atributos
- **`__init__`**: Constructor de la clase
- **`__str__`**: Representación en string del objeto
