# 01 - Estructura HTML

## Descripción

Proyecto para aprender las etiquetas básicas de HTML y la estructura
semántica de una página web.

## Qué aprenderé

- Estructura básica de un documento HTML
- Etiquetas semánticas (header, nav, main, footer)
- Encabezados (h1-h6)
- Párrafos, listas, enlaces e imágenes
- Tablas básicas

## Archivos del proyecto

- `index.html` - Página con estructura básica
- `semantica.html` - Ejemplo de HTML semántico
- `tablas.html` - Ejemplos de tablas

## Cómo ver

Abre los archivos `.html` directamente en tu navegador (doble clic o click derecho > Abrir con > Chrome/Firefox)

## Conceptos clave

- **`<!DOCTYPE html>`** - Declara que es HTML5
- **`<html>`** - Contenedor principal
- **`<head>`** - Metadatos (título, charset, etc)
- **`<body>`** - Contenido visible
- **Etiquetas semánticas** - Dan significado al contenido
