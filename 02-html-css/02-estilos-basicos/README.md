# 02 - Estilo Básico

## Descripción 

Proyecto para entender los fundamentoso de CSS: selectores, colores, fuentes, espaciado y el modelo de caja (box model)

##  Qué aprenderé

- Conectar CSS con HTML
- Selectores básicos (elementos, clase, id)
- Colores (hex, rgb, nombres)
- Fuentes y texto
- box model (margin, padding, border)
- Unidades (px, %, em, rem)

## Archivos del proyecto

- `index.html` - Página HTML
- `style.css` - Archivo de estilos
- `selectores.html` - Ejemplos de selecores
- `box-model.html` - Ejemplos de box model

## Cómo ver

Abre los archivos `.html` directamente en tu navegador

## Conceptos claves

- **Selectores de elemento**: `p { }` (todos los párrafos)
- **Selectores de clase**: `.nombre { }` (clase="nombre")
- **Selectores de id**: `#nombre { }` (id="nombre")
- **Box model**: content → padding → border → margin
- **Colores**: `#ff0000`, `rgb(255, 0, 0)`, `red`
