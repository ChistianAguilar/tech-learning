# 03 - Flexbox y Grid

## Descripción 

Proyrcto para aprender las dos herramientas más poderosas de CSS para crear layouts modernos y responsivos.

## Qué aprenderé 

- Flexbox para layouts en una dimensión (fila o columna)
- CSS Grid para layouts en dos dimensiones (filas y columnas)
- Alineación y distribución de elementos
- Diseño responsivo básico

## Archivos del proyecto 

- `flexbox.html` - Ejemplos con Flexbox
- `flexbox.css` - Estilos para Flexbox
- `grid.html` - Ejemplos con Grid
- `grid.css` - Estilos para Grid

## Cómo ver

Abre los archivos `.html` directamente en tu navegador

## Conceptos claves

**Flexbox:**
- `display: flex` - Activa flexbox
- `justify-content` - Alineación horizontal
- `align-items` - Alineación vertical
- `flex-direction` - Dirección (row, column)

**Grid:**
- `display: grid` - Activa grid
- `grid-template-columns` - Define columnas
- `grid-template-rows` - Define filas
- `gap` - Espacio entre elementos
