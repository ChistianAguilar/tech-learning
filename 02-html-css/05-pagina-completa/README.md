# 05 - Página Completada (Portafolio personal)

## Descripción

Proyecto final que integra todos los conocimientos de HTML y CSS en una página portafolio personal profecional.

## Qué aprenderé

- Integrar HTML semántico
- Aplicar Flexbox y Grid en un proyecto real
- Crear una página responsiva
- Diseño limpio
- Navegación entre secciones

## Archivos del proyecto

- `index.html` - Página principal portafolio
- `styles.css` - Todos los estilos

## Cómo ver

Abre `index.htmlp` directamente en tu navegador

## Conceptos integrados

- Estructura HTML semántica
- Selectores CSS avanzados
- Box model
- Flexbox para layouts
- Grid para selecciones
- Formulario de contacto
- Diseño responsivo
