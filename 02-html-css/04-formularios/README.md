# 04 - Formularios 

## Descripción 

Proyecto para aprender a crear formularios HTML con diferentes tipos de inputst y cómo darles estilos profecionales con CSS.

## Qué aprendere

- Estructura básica de un formulario
- Diferentes tipos de imputs (text, email, password, number, etc.)
- Elementos de selección (select, radio, checkbox)
- Textarea para texto largo
- Validación HTML5
- Estilo CSS para formularios

## Archivos del proyecto

- `registro.html` - Formulario de registro completo
- `contacto.html` - Formulario de contacto
- `formularios.css` - Estilos para ambos formularios

## Cómo ver

Abre los archivos `.html` directamente en tu navegador

## Conceptos clave

- **`<form>`** - Contenedor del formulario
- **`<input>`** - Campo de entrada
- **`<label>`** - Etiqueta descriptiva
- **`<select>`** - Lista desplegable
- **`<textarea>`** - Área de texto
- **`required`** - Campo obligatorio
- **`placeholder`** - Texto de ayuda
